# プライバシーポリシー

最終更新日：2026年5月11日

本プライバシーポリシーは、当方が提供するモバイルアプリケーション「Film Vault」（以下「本アプリ」といいます。）における、ユーザー情報の取扱いについて定めるものです。

## 第1条（本アプリで取り扱う情報）
本アプリは、サービスの提供にあたり、以下の情報を取り扱います。ユーザーがアプリ内に保存する情報や写真解析に利用する情報は、原則としてユーザーのデバイス上で保存または処理されます。

1. **ユーザーがアプリ内に保存する情報**
    * レシピ名
    * メモ
    * 作成・更新日時
    * フィルムシミュレーション設定（ホワイトバランス、トーン、カラー、シャープネス等の設定値）
    * お気に入り状態
    * 写真アセットのローカル識別子（写真ライブラリ上の識別子）
2. **写真ライブラリから読み込む情報**
    * ユーザーが選択または紐づけた写真データ
    * 写真の EXIF / MakerNote に含まれるメタデータ（カメラ機種、レンズ、撮影日時、撮影設定、GPS 情報など）
3. **レシピ取り込み時に処理する情報**
    * ユーザーが選択したスクリーンショットから文字認識されたテキスト
    * 対応サイトの Web ページ本文、URL、タイトル
4. **外部サービスを通じて取得または送信されることがある情報**
    * **Firebase Analytics:** 画面表示、ボタン操作、追加方法、サイト選択、保存レシピ数、サブスクリプション状態など、利用状況に関する情報
    * **Firebase Crashlytics:** クラッシュログ、端末・OS・アプリバージョン等の診断情報、内部エラー情報
    * **Google Mobile Ads:** 広告配信に関連する情報。ユーザーが App Tracking Transparency による許可を行った場合、広告識別子等が利用されることがあります
    * **Apple StoreKit:** 月額・年額の Plus 購読状態に関する情報。決済情報そのものは Apple が管理します

## 第2条（利用目的）
当方は、取り扱う情報を以下の目的で利用します。

1. **本アプリの提供および改善のため**
    * ユーザーが作成・管理するフィルムシミュレーションレシピの保存、編集、表示
    * 写真ライブラリの写真とレシピの紐づけ
    * 写真のメタデータ（EXIF / GPS 等）に基づく FUJIFILM のレシピ設定候補の抽出
    * スクリーンショットや Web ページからの文字認識・テキスト抽出によるレシピ案の生成
    * アプリ内ブラウザを通じた外部サイト（FUJIFILM Stories / FUJI X Weekly など）の閲覧およびレシピ取り込み機能の提供
    * ユーザーが保存したレシピやメモへの反映
2. **利用状況の分析およびサービス向上のため**
    * Firebase Analytics を用いた利用状況の分析、機能改善、新機能開発
3. **不具合の検知および修正のため**
    * Firebase Crashlytics を用いたクラッシュログやエラー情報の収集、原因究明および修正
4. **広告表示のため**
    * Google Mobile Ads を用いた広告配信
5. **課金処理およびサブスクリプション管理のため**
    * Apple StoreKit を用いた Plus 購読状態の管理

## 第3条（第三者提供）
当方は、法令に基づく場合または本人の同意を得た場合を除き、取り扱う情報を第三者に提供することはありません。ただし、第4条に定める外部サービスへの情報送信は、本ポリシーに定める範囲内で行われます。

## 第4条（外部サービスの利用）
当方は、本アプリの提供にあたり、以下の外部サービスを利用します。各サービスにおける情報の取扱いについては、各サービスのプライバシーポリシーをご確認ください。

1. **Firebase Analytics (Google LLC)**
    * 利用目的: アプリケーションの利用状況の分析
    * プライバシーポリシー: [https://policies.google.com/privacy](https://policies.google.com/privacy)
2. **Firebase Crashlytics (Google LLC)**
    * 利用目的: アプリケーションのクラッシュレポートおよびエラー情報の収集
    * プライバシーポリシー: [https://policies.google.com/privacy](https://policies.google.com/privacy)
3. **Google Mobile Ads (Google LLC)**
    * 利用目的: アプリケーション内での広告配信
    * プライバシーポリシー: [https://policies.google.com/privacy](https://policies.google.com/privacy)
4. **Apple StoreKit (Apple Inc.)**
    * 利用目的: アプリ内課金およびサブスクリプション管理
    * プライバシーポリシー: [https://www.apple.com/jp/legal/privacy/](https://www.apple.com/jp/legal/privacy/)

## 第5条（Apple Intelligence / Foundation Models の利用）
本アプリの一部の機能では、Apple Intelligence の Foundation Models フレームワークを利用してレシピ案を生成します。Foundation Models による処理は、対応するデバイス上で実行されます。

### 5.1 処理される情報
レシピ案生成のために、以下の情報がユーザーのデバイス上で一時的に処理されることがあります。

1. スクリーンショットから文字認識されたテキスト
2. 対応サイトのページ本文から抽出されたテキスト
3. レシピ案生成に必要な一時的な処理データ

### 5.2 外部送信の有無
当方は、Foundation Models を利用したレシピ案生成のために、上記のテキストやレシピ案生成データを当方のサーバーまたは外部の生成 AI API へ送信しません。

### 5.3 利用目的
Foundation Models は、ユーザーが選択したスクリーンショットまたは対応サイトのページ本文に基づいて、フィルムシミュレーションレシピ案を生成するために利用されます。

### 5.4 ユーザーの選択
レシピ案生成機能を利用しない場合でも、ユーザーはレシピの手動作成、編集、閲覧などの基本機能を利用できます。

## 第6条（データの保管および削除）
1. ユーザーがアプリ内に保存するレシピ、メモ、写真アセットのローカル識別子等のデータは、ユーザーのデバイス上にローカルに保管されます。
2. ユーザーは、本アプリの機能を通じて、保存したレシピや関連データを削除することができます。
3. ユーザーが本アプリをアンインストールした場合、原則としてユーザーのデバイス上に保管されていた本アプリのデータは削除されます。
4. Firebase Analytics、Firebase Crashlytics、Google Mobile Ads などの外部サービスに送信された情報は、各サービスのポリシーおよび保存期間に従って取り扱われます。

## 第7条（安全管理措置）
当方は、取り扱う情報について、不正アクセス、漏洩、滅失、毀損等を防止するため、必要かつ適切な安全管理措置を講じます。

1. デバイス上のデータは、OS の標準的なセキュリティ機能によって保護されます。
2. 外部サービスへのデータ送信は、暗号化された通信（SSL/TLS 等）を用いて行われます。
3. 外部サービスの管理画面等へのアクセス権限を適切に管理します。

## 第8条（お子様の利用）
本アプリは、13歳未満のお子様による利用を主たる対象としていません。13歳未満のお子様が本アプリを利用される場合は、保護者の同意および監督のもとでご利用ください。

## 第9条（本ポリシーの変更）
当方は、必要に応じて本プライバシーポリシーを変更することがあります。変更後のプライバシーポリシーは、本アプリまたは当方の Web サイトに掲載した時点から効力を生じます。
