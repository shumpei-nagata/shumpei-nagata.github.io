# 特定商取引法に基づく表記

最終更新日：2026年5月11日

| 項目 | 内容 |
|---|---|
| 販売事業者 | 個人事業主のため、請求があった場合には法令に基づき遅滞なく開示いたします。 |
| 運営責任者 | 請求があった場合には法令に基づき遅滞なく開示いたします。 |
| 所在地 | 請求があった場合には法令に基づき遅滞なく開示いたします。 |
| 電話番号 | 請求があった場合には法令に基づき遅滞なく開示いたします。 |
| 開示請求・お問い合わせ先 | 購入申込み前の開示請求および本アプリに関するお問い合わせは、[こちらのフォーム](https://docs.google.com/forms/d/e/1FAIpQLSe9PfBmqnxaW-GyOcD9-jKdHgspUNsgIAJ7wsUFwjzKvZrEog/viewform?usp=dialog)からご連絡ください。 |
| 販売価格 | アプリ内の購入画面に表示されます。Plus購読は、App Storeのアプリ内課金として提供されます。 |
| 商品代金以外の必要料金 | 本アプリのダウンロード、利用、アップデート等に伴うインターネット接続料、通信料等は利用者のご負担となります。 |
| 支払方法 | App Store決済（Apple IDに登録された支払方法）によりお支払いいただきます。 |
| 支払時期 | 購読開始時に決済されます。Plus購読は自動更新サブスクリプションとして提供され、解約されない限り、購読期間の更新時に自動的に決済されます。 |
| 商品の引渡時期 | 購読手続き完了後、即時に有料機能をご利用いただけます。 |
| 返品・キャンセル | デジタルコンテンツの性質上、購入後の返品・キャンセルは原則としてお受けしておりません。返金の可否および手続きは、Appleの規約および返金ポリシーに従います。 |
| サブスクリプションの解約 | App Storeの購読管理画面からいつでも解約できます。自動更新を停止するには、次回更新日の24時間以上前までに解約手続きを行う必要があります。解約後も、現在の購読期間が終了するまでは有料機能をご利用いただけます。 |
| 商品の利用期間 | Plus購読の利用期間は、購入された購読期間に準じます。 |
| 動作環境 | iOS 26.4以降を搭載したiPhoneまたはiPad。インターネット接続環境が一部機能で必要です。 |
